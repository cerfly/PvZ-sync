Notes
-----
* The OBB filename embeds the versionCode. Any build other than 1055 needs a
  differently-named OBB, and a mismatch produces the in-game error
  "Download failed because the resources could not be found".
* Secondary Android users each need their own copy of the OBB. The adb shell
  (uid 2000) cannot read or write /storage/emulated/<otherUserId>, so the copy
  must be fetched by the Play Store while inside that user, or placed by a file
  manager running as that user.
* com.ea.game.pvz2_row is the same EA build (13.4.1 / 1055) under a different
  package name for Rest-of-World regions. It is a DIFFERENT app: separate data
  directory, separate OBB filename, and the save tree here does not apply to it.
